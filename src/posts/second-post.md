# React + Markdown is a Great Combo

Using `react-markdown` to render content makes writing blog posts so much easier.

## Why Markdown?

- Easy to write
- Readable as plain text
- Converts cleanly to HTML

## Code Example

```js
import ReactMarkdown from 'react-markdown';

<ReactMarkdown>{content}</ReactMarkdown>
```

That's all it takes!
